# Digital Signal Processing & Analysis Tool

A simple Python GUI tool built for DSP Lab.

## Features
- Generate Sample Sine Wave Signal
- Load Signal from CSV file
- Calculate RMS Value
- Find Dominant Frequency using FFT
- Visual Graph Representation

## Tech Stack
- Python
- NumPy, SciPy, Matplotlib, Tkinter

## How to Run
pip install numpy matplotlib scipy
python main.py
